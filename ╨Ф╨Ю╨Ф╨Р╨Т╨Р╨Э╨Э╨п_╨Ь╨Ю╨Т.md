# Як додати нову мову (окремий файл, як для норвезької)

## Коротко
1. Скопіюй `js/data-en.js` під новою назвою, наприклад `js/data-de.js`.
2. Заміни вміст на словник/граматику потрібної мови (структура полів — точно
   така сама, міняється лише текст).
3. У самому кінці файлу заміни `LANG_DATA.en` на `LANG_DATA.de` (код мови).
4. Додай рядок у `index.html` одразу після `js/data-en.js`:
   ```html
   <script defer src="js/data-de.js"></script>
   ```
5. Готово — сайт сам підхопить нову мову. Нічого більше міняти не треба.

## Чому саме так
Кожен файл — це звичайний `<script>`, без `import`/`export` (щоб не
переписувати весь сайт на ES-модулі). Кожен файл загорнутий у
`(function () { ... })()`, щоб його власні `const VOCAB`, `const GRAMMAR`
тощо не конфліктували з такими самими іменами в інших файлах. У кінці файл
сам себе реєструє: `window.LANG_DATA.de = { VOCAB, GRAMMAR, NORSKPROVE_TASKS, LEVEL_TEST };`

Решта сайту (словник, картки, тести, граматика, тест на рівень) вже вміє
перевіряти `LANG_DATA[мова]` для БУДЬ-ЯКОЇ мови — і використовує знайдений
файл замість AI-генерації. Якщо файлу для мови нема — усе працює як
раніше, через AI.

## Формат полів

### VOCAB (обов'язково для кожного з 6 рівнів A1-C2, можна лишити `[]`)
```js
{
  t: "Тема українською (наприклад Їжа, Транспорт)",
  no: "слово мовою вивчення",      // так, поле історично зветься "no", але це просто "слово цієї мови"
  uk: "переклад українською",
  ex_no: "приклад речення мовою вивчення",
  ex_uk: "переклад прикладу",
  en: "переклад англійською",       // потрібно, якщо STATE.vocabLang = 'en'
  en_ex: "приклад англійською",
  ru: "переклад російською",        // потрібно, якщо STATE.vocabLang = 'ru'
  ru_ex: "приклад російською",
}
```

### GRAMMAR (масив правил, можна лишити `[]`)
```js
{
  id: "de_gr1", level: "A1",
  title: "Назва правила українською", exp: "Пояснення українською.",
  table: { head: ["Колонка1", "Колонка2"], rows: [["...", "..."]] },
  ex: { q: "Питання-приклад українською", opts: ["варіант1","варіант2","варіант3"], a: 0 },
  title_en: "...", title_ru: "...",   // те саме англійською/російською
  exp_en: "...", exp_ru: "...",
  head_en: [...], head_ru: [...],
  q_en: "...", q_ru: "...",
}
```

### NORSKPROVE_TASKS (вправи читання/аудіювання/письма/усного — можна лишити порожнім)
```js
{
  A1: { reading: [{ title, text, questions: [{q, opts, a}] }], listening: [], writing: [], speaking: [] },
  A2: { ... }, B1: { ... }, ... C2: { ... },
}
```

### LEVEL_TEST (питання для вхідного тесту на рівень, можна лишити `[]` —
тоді використовується AI-генерація, як зараз для всіх мов без файлу)
```js
{ lvl: "A1", q: "Питання українською", opts: [...], a: 0,
  q_en: "...", opts_en: [...], q_ru: "...", opts_ru: [...] }
```

## Де брати словники
Якщо шукаєш готові списки слів за рівнями CEFR (A1-C2) для конкретної
мови — це та частина роботи, яку ти хотів взяти на себе, щоб уникнути
помилок AI. Далі просто вставляєш знайдені слова/переклади у формат вище.
Я можу допомогти звести будь-який знайдений список у потрібний JS-формат,
якщо накидаєш його мені — не обов'язково вручну форматувати кожне слово.
